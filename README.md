# 🖨️ Integração C com Impressora Elgin i9

**CPrinter**

## 📘 Sobre o Projeto

Este projeto foi desenvolvido por alunos com o objetivo de criar uma aplicação em **C** capaz de se comunicar com a impressora **Elgin i9**, utilizando comandos **ESC/POS**, testes de impressão e interação via porta de comunicação.

O trabalho faz parte da disciplina de **Programação Orientada a Objetos**.

## 🧰 Tecnologias Utilizadas

- Linguagem C (padrão C11)
- Código: Dev C++
- Biblioteca ESC/POS
- Driver/SDK da Elgin i9
- *(Opcional)* Maven ou CMake

## 📁 Estrutura do Projeto

| Pasta | Conteúdo |
|---|---|
| `/src` | Código-fonte principal |
| `/lib` | Bibliotecas e dependências externas |
| `/docs` | Materiais adicionais e documentação |
| `/examples` | Testes e arquivos de demonstração |

## ⚙️ Instalação e Execução

### 🔽 1. Baixar o Projeto do GitHub

1. Acesse o repositório: <https://github.com/MaAlmeida11/projetoimpressora>
2. Clique no botão **Code**.
3. Selecione **Download ZIP**.
4. Aguarde o download.

### 📦 2. Extrair o Arquivo ZIP

1. Vá até o local onde o arquivo foi salvo.
2. Clique com o botão direito → **Extrair aqui** / **Extrair tudo**.
3. Será criada uma nova pasta com os arquivos.

### 🧭 3. Importar no Dev C++

1. Abra o **Dev C++**.
2. Clique em **Arquivo → Abrir**.
3. Escolha a pasta extraída.
4. Aguarde o carregamento.
5. Selecione o arquivo `projeto.c`.
6. Clique em **Abrir**.
