🖨️ Integração C com Impressora Elgin i9
CPrinter

📘 Sobre o Projeto
Este projeto foi desenvolvido por alunos com o objetivo de criar uma aplicação C capaz de se comunicar com a impressora Elgin i9, utilizando comandos ESC/POS, testes de impressão e interação via porta de comunicação.
O trabalho faz parte da disciplina de Programação Orientada a Objetos.

🧰 Tecnologias Utilizadas
Linguagem C (padrão C11)
Código: Dev C++
Biblioteca ESC/POS
Driver/SDK da Elgin i9
(Opcional) Maven ou CMake

📁 Estrutura do Projeto
/src → Código-fonte principal /lib → Bibliotecas e dependências externas /docs → Materiais adicionais e documentação /examples → Testes e arquivos de demonstração

⚙️ Instalação e Execução
🔽 1. Baixar o Projeto do GitHub
Acesse o repositório: https://github.com/MaAlmeida11/projetoimpressora.
Clique no botão Code.
Selecione Download ZIP.
Aguarde o download.
📦 2. Extrair o Arquivo ZIP
Vá até o local onde o arquivo foi salvo.
Clique com o botão direito → Extrair aqui / Extrair tudo.
Será criada uma nova pasta com os arquivos.
🧭 3. Importar no Dev C++
Abra o Dev C++.
Clique em Arquivo → Abrir.
Escolha a pasta extraída.
Aguarde o carregamento.
Selecione o projeto.c.
Clique em Abrir.
